# One Line, One Laugh

An entry for the make.fun "One Line, One Laugh" bounty (`u-deysumbrella-one-line-one-laugh-e0cdcda9`).

## Description

A single punchy, humorous line designed to land a laugh in one breath. When executed, `main.py` prints the line to stdout and writes the exact same single line into `output/entry.txt` (126 characters, well within the 1 to 140 character limit).
